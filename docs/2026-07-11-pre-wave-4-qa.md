Date: 2026-07-11
Environment: local `dev` branch, Node.js 24, AMPPS MySQL, Vite development server
Scope: Wave 1-3 regression smoke test and Wave 4 foundation readiness

## Verdict

**Go for Wave 4 implementation.** The application, database, role-based access, primary COD order flow, and home-page quick-add regression check are operational. VNPay end-to-end testing remains blocked only by sandbox credentials that must be supplied outside the repository.

## Findings

### Resolved - Customer home quick-add now writes to the server cart

Original reproduction:

1. Sign in as `mara@example.com` with the documented demo password.
2. On `/app`, add **Margherita** from **Các món thịnh hành gần bạn**.
3. Open the cart and proceed to checkout.
4. Submit the COD order.

Original result: the UI showed the item and total, but order creation failed with **Giỏ hàng rỗng**. The toast also incorrectly said **Hãy đăng nhập để đặt món** although the customer was authenticated.

Resolution: the home API now supplies price, restaurant metadata, and the real menu item ID. The trending carousel uses this server data, and authenticated carts reject incomplete items instead of creating a local-only cart.

Verification: adding **Margherita** from `/app` created server cart item `menuItemId=1`, quantity `1`, displayed the synchronized-cart state, and produced no browser console warnings. The test cart was deleted afterward.

### External prerequisite - VNPay sandbox credentials are not available locally

The local sandbox URLs, return URL, and IPN URL are configured. These credentials remain empty:

- `VNPAY_TMN_CODE`
- `VNPAY_HASH_SECRET`

Do not commit their real values. Add the credentials locally before CUS-05 end-to-end testing.

### Resolved - Frontend lint and chart warnings

React hook dependencies were corrected, onboarding forms now use `useWatch`, and chart containers have a stable minimum width. ESLint now passes with zero errors and zero warnings, and the merchant dashboard browser check has a clean console.

### Test coverage gap

A Node test command and two focused regression tests now cover transformation of home API items into server-backed cart items. Broader automated API and browser coverage is still not configured and should be expanded during Wave 4.
